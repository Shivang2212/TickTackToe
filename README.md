# ❌ Tic-Tac-Toe Game ⭕

A classic, lightweight, and responsive **Tic-Tac-Toe** web game built using vanilla HTML, CSS, and JavaScript. 

---

## 🚀 Features

* **Interactive UI:** Clean and modern interface styled with custom CSS.
* **Two-Player Mode:** Take turns playing locally with a friend.
* **Win/Draw Detection:** Instantly detects winning rows, columns, diagonals, or a tie game.
* **Responsive Design:** Optimized to play smoothly across different screen sizes.
